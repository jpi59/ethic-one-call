# Ethic One Call

Ethic One Call helps a phone owner prepare a temporary, single-call handoff.
It opens Android's Phone app and explains how to use the system screen-pinning
feature before lending the device.

The app does not request contacts, call-log, SMS, accessibility, overlay, or
network permissions. It cannot silently pin another app: Android reserves that
control for the system or managed device owners. The owner must enable screen
pinning and pin Phone from Recents; Android then protects the exit with the
device PIN or biometric authentication.
